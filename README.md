## 관리자가 할 수 있는 일 (상단 '관리자' 메뉴)
- **회원·등급**: 회원 검색, 등급 변경(이음·누림·새움·피움·이룸·드림), 회원 상세정보, 추천인 수정
- **창업접수**: 접수글 확인 → `새움 승인` 버튼 한 번으로 등업 + 온라인 강의 오픈
- **렌탈상품**: 상품 추가·수정·삭제·순서 변경, 상품별 온라인 렌탈계약 링크 입력 → QR 자동 생성
- **제품자료·영상**: 유튜브 링크/영상 파일, 설명자료 이미지(여러 쪽)·PDF 링크 등록
- **온라인강의**: 1부(필수 3시간)·2부(자율 6시간) 강의 영상 등록
- **매장**: 매장 주소·전화·사진 입력 (기본 6개 매장과 네이버 플레이스 링크 등록됨)
- **사이트 설정**: 구글폼 링크, 교육비, 입금 계좌, 앱 링크, 추천인 기본값 등
- **백업**: 데이터 백업 파일 내려받기 / 복원

## ⚠️ 꼭 알아두세요: 데이터 저장 방식
순수 HTML/CSS/JS에는 서버가 없어서, 현재 회원·게시판·설정 데이터는 **각 방문자의 브라우저 안에만** 저장됩니다.
- 화면과 기능은 모두 동작하지만, A가 가입한 정보를 관리자 컴퓨터에서 볼 수는 없습니다.
- 실제 운영하려면 `js/store.js`의 `load()` / `persist()` 두 함수를 Firebase·Supabase 같은 서버 저장소로 연결하면 됩니다. 나머지 화면 코드는 바꿀 필요가 없도록 분리해 두었습니다.

## 파일 구조
```
index.html            메인 (모든 화면이 이 파일 안에서 전환됩니다)
css/style.css         디자인
js/config.js          기본 설정 (구글폼, 추천인, 앱 링크, 관리자 계정)
js/store.js           데이터 저장소
js/hero3d.js          메인 3D 연출 (X-ray 자세 교정 → 조깅)
js/app.js             화면·게시판·회원·관리자 기능
assets/products/      제품 사진 (안내서에서 추출)
assets/brochure/      창업 안내서 페이지 (제품소개 > 설명자료에 등록됨)
assets/vendor/        three.js(3D), QR 코드 라이브러리
```
